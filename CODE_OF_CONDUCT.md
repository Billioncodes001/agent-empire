# Code of conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. The full text at that address is the reference text and applies in full to every project space: issues, pull requests, discussions, reviews and any community channel linked from this repository.

In short: be welcoming and respectful, give and accept constructive feedback, and focus on what is best for the community. Harassment, insults, sexualised language or imagery, publishing others' private information, and other conduct that would be inappropriate in a professional setting are not acceptable.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@Billioncodes001](https://github.com/Billioncodes001), through a [private security advisory](https://github.com/Billioncodes001/agent-empire/security/advisories/new) titled "Code of conduct" (this keeps the report private), or through GitHub's [report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature. All reports are reviewed promptly and kept confidential.

Enforcement follows the Contributor Covenant 2.1 enforcement guidelines: correction, warning, temporary ban, permanent ban.
